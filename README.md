# Legit — Player Tools

Собственный интерфейс **Player Tools**: тёмная панель с фиолетовыми переключателями, ползунками, прокруткой и перетаскиванием. Доступны 8 вкладок и 109 настроек ESP, наведения и Melee Aura.

## Запуск

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/sinmirka/Legit/main/Legit.lua"))()
```

Один файл, одна HTTP-загрузка. Интерфейс и логика встроены в `Legit.lua`. Приложение использует стандартный Roblox GUI; внешние UI-библиотеки, Drawing API, PNG и `getcustomasset` для запуска не нужны.

Нужны `loadstring`, `getgenv` и файловые функции для профилей. ESP и Aimbot изначально выключены. Старый экземпляр при повторном запуске выгружается.

По умолчанию проверка команды и исключение ForceField отключены: цели выбираются среди остальных живых игроков. Эти фильтры можно включить отдельно.

## Управление

| Действие | По умолчанию |
| --- | --- |
| Открыть / закрыть меню | **RightShift** |
| Наведение | **Удерживать ПКМ**, после включения Enable aimbot |
| Изменить клавишу наведения | Aim → Aim key, затем нажать нужную клавишу / кнопку мыши |
| Очистить привязку | Выбрать Aim key и нажать **Backspace** |
| Выгрузить UI, ESP и наведение | **END** или Profiles → Unload |

Наведение работает при открытом меню, когда курсор находится вне панели. Клик по настройкам, ввод текста и перетаскивание приостанавливают наведение. Можно отдельно включить Pause while menu is open.

Значение ползунка можно ввести прямо в числовое поле. Цвет задаётся через HEX или поля R/G/B; отдельный ползунок регулирует его Opacity. Нажатие на поле выбора переключает следующее значение.

### Цвета и прозрачность

- **Opacity**: `0` — невидимо, `1` — непрозрачно.
- Итоговая видимость Chams учитывает Global opacity, Fill opacity и прозрачность выбранного цвета. Fade и Pulse дополнительно изменяют её.
- Приоритет цвета персонажа от высшего к низшему: **текущая цель → rainbow → цвет команды → видимый / скрытый → базовый цвет**. Выключи переопределения, если хочешь видеть базовые Fill / Outline.
- Для независимого цвета рамки выключи **Match character color**. Прозрачность текста и его обводки регулируются отдельно.
- **Character outline** — силуэт Highlight со стандартной толщиной Roblox. Настраиваемая толщина относится к 2D-рамкам, скелету, линиям и FOV.

### Выбор цели

FOV — радиус в пикселях вокруг центра экрана. Deadzone останавливает поворот камеры, когда цель достаточно близко к центру; выбранная цель при этом сохраняется. Большая Aim speed означает более быстрое наведение. Instant убирает плавность.

Для R6 выбор UpperTorso / LowerTorso использует Torso, а UpperArm / UpperLeg — соответствующие Arm / Leg. Другие отсутствующие части тела исключают цель. Смещение XYZ задаётся в мировых координатах; prediction добавляет скорость HumanoidRootPart × Prediction time. Наведение поворачивает камеру; стрельба и регистрация попаданий остаются механиками игры.

Check walls проверяет путь до выбранной части тела. ESP проверяет видимость до головы; для Highlight дополнительно применяется режим Occluded. Для 2D-элементов проверка головы определяет отображение всего оверлея. Прозрачное стекло с CanQuery может считаться препятствием; вода игнорируется.

### Если нет наведения

Включи Aim → Enable aimbot, скрой меню через RightShift и удерживай ПКМ. Состояние показано внизу окна, а при скрытом меню — рядом с кнопкой TOOLS: ожидание клавиши, ввод текста, выбранный игрок или причины исключения целей — team, wall, FOV, distance, body part. Если все игроки находятся в одной Roblox Team, выключи Skip teammates; если цель вне круга, увеличь FOV radius.

Исправлена обработка ПКМ, которую игра помечает как обработанную. В Hold проверяется текущее состояние клавиши, включая пропущенные события нажатия и отпускания. Камера обновляется после обычных контроллеров; Scriptable-камера по умолчанию допускается. Опции полного запрета наведения при открытом меню и на Scriptable-камере доступны, но изначально выключены.

### Профили

Укажи имя на вкладке Profiles и нажми **Save profile**. Файлы сохраняются в файловой области executor: `Legit/Universal/configs/<имя>.json`. Сохраняются настройки функций, клавиша, RGB и прозрачность цветов, а также акцент UI. **Load profile** загружает выбранное имя; автоматической загрузки при старте нет.

Для имени разрешены латинские буквы, цифры, пробел, `_` и `-`, до 48 символов. Reset defaults возвращает исходные настройки, включая выключенные ESP и Aimbot. Активное удержание / Toggle при загрузке профиля сбрасывается.

### Melee Aura для Criminality

Экспериментальный модуль: совместимость с текущей Criminality и конкретным executor в живой игре не проверена. Включи **Melee → Enable melee aura**, экипируй melee-инструмент и закрой меню. По умолчанию дальность — 10 studs до выбранной части тела, интервал активации — 0.5 s, окно перенаправления лучей после удара — 0.35 s. Выключи **Auto attack**, чтобы бить вручную с перенаправлением лучей. **Show melee status** показывает выбранную цель, паузу, отсутствие оружия или недоступность hook API.

Поддерживаемые имена инструментов: Fists, Knuckledusters, Nunchucks, Shiv, Bat, Metal-Bat, Chainsaw, Balisong, Rambo, Shovel, Sledgehammer, Katana, Wrench, Fire Axe. Неизвестные инструменты не активируются. Для UpperTorso у R6 используется Torso. Цель выбирается вокруг персонажа на 360°, без экранного FOV. Фильтры Melee независимы от Aim и ESP. Ввод текста, работа с контролами меню, потеря фокуса и смерть персонажа приостанавливают функцию.

Нужны `hookmetamethod`, `getnamecallmethod`, `checkcaller`, `getcallingscript`; `newcclosure` используется при наличии. Hook устанавливается при первом включении и обрабатывает только `workspace:Raycast` из скрипта экипированного инструмента либо модуля с `RaycastHitbox` в имени, во время окна удара. Начало луча должно находиться рядом с персонажем, а длина входящего луча не должна превышать Reach + 6 studs. Прямые вызовы `workspace.Raycast(...)`, другие hitbox API и переименованные общие модули не перехватываются.

Перенаправляется направление настоящего Raycast; его параметры фильтрации и результат сохраняет движок Roblox. При этом луч может удлиниться до цели. Auto attack вызывает `Tool:Activate()`: игровые cooldown, анимации, проверки дистанции и серверная регистрация попаданий продолжают действовать. Увеличение Reach не гарантирует попадание. При выключении и выгрузке обработчик пропускает все вызовы; один общий dispatcher повторно используется при перезапуске, без накопления hooks и без перезаписи hooks других скриптов.

При исследовании просмотрен [публичный пример Criminality](https://github.com/Trojankill/Criminality/blob/main/CriminalityV2.lua): там Melee Aura основана на remote-вызовах. Здесь реализован отдельный Raycast-подход, без загрузки и выполнения стороннего скрипта или копирования его remote-протокола.

## Проверка

Рабочие Lua-файлы компилируются `luau-compile` 0.746. Проверки запускают собственный интерфейс и логику с заглушками Roblox:

```shell
python tests/run.py --luau /path/to/luau
```

Проверены клики по контролам, числовой/HEX/RGB ввод, привязка клавиши, размеры панели, профили, цвета, фильтры целей, R6, FOV, стены, prediction, ESP и очистка. Через настоящий render callback проверены наведение при пропущенном InputBegan, обработанный игрой ПКМ, открытое меню, Scriptable-камера, отпускание клавиши без InputEnded, блокировка при вводе текста и причины отсутствия цели.

Отдельно проверен однострочник из README: один HTTP-запрос, запуск без Drawing и getcustomasset, отсутствие загрузки зависимостей и повторный запуск.

Для Melee Aura проверены границы hook, сохранение аргументов и результата Raycast, фильтры целей, смерть и выход из дальности между кадрами, интервал автоатаки, ручные удары и истечение окна, пауза, профили, очистка соединений, повторное использование hook и отсутствие нужных API. Эти проверки используют заглушки и не подтверждают серверную регистрацию урона.

Это проверка логики с заглушками. Визуальный запуск в Roblox и совместимость с конкретным executor в этой среде не проверялись. Пользовательские персонажи, собственные системы команд / здоровья и другие скрипты камеры могут требовать адаптации. Персонажи, не загруженные на клиент из-за StreamingEnabled, недоступны для ESP и наведения.

## Исходники

- `Legit.lua` — автономный файл для однострочного запуска; сборка: `python tools/build_bundle.py`.
- `main.lua` — исходник приложения, настройки и профили.
- `src/NativeUI.lua` — собственный интерфейс Player Tools.
- `src/Engine.lua` — ESP, выбор целей, управление камерой и очистка.
- `src/MeleeAura.lua` — Melee Aura, фильтры целей, автоактивация оружия и Raycast hook.
- `src/GuiDrawing.lua` — стандартные Roblox GUI-примитивы для ESP/FOV.
- `vendor/Tokyo.lua`, `assets/` — сохранённые исходники предыдущей версии; приложение их не использует.
- `tests/` — проверки без запуска Roblox.

Происхождение библиотеки и список исправлений: [THIRD_PARTY.md](THIRD_PARTY.md).
