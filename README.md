# Legit — Tokyo UI

ESP и наведение камеры с интерфейсом на **Tokyo Lib**: 7 вкладок и 96 элементов настроек. Используется приложенная библиотека из `vendor/Tokyo.lua`; UI не подменяется собственной панелью.

## Запуск

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/sinmirka/Legit/main/main.lua"))()
```

Запуск через executor с поддержкой **Drawing API**, `loadstring`, `getgenv`, `game:HttpGet` и файловых функций `makefolder`, `isfile`, `readfile`, `writefile`. Обычный LocalScript в Studio для этой версии не подходит. Если отсутствует нужная функция, загрузчик укажет её название.

Скрипт загружает Tokyo Lib, модуль логики и изображения из этого репозитория. Код Signal встроен в библиотеку; зависимости от удалённого Signal и `crypt.base64decode` удалены. При повторном запуске предыдущая копия выгружается.

## Управление

| Действие | По умолчанию |
| --- | --- |
| Открыть / закрыть меню | **RightShift** |
| Наведение | **Удерживать ПКМ**, после включения Enable aimbot |
| Изменить клавишу наведения | Aim → Aim key, затем нажать нужную клавишу / кнопку мыши |
| Очистить привязку | Выбрать Aim key и нажать **Backspace** |
| Выгрузить UI, ESP и наведение | **END** или Profiles → Unload |

ESP и Aimbot изначально выключены. По умолчанию наведение приостанавливается, пока меню открыто. Для ползунков Tokyo также поддерживает точный ввод через **Ctrl + клик** по полю значения. В окне выбора цвета доступны палитра и прозрачность.

### Цвета и прозрачность

- **Opacity**: `0` — невидимо, `1` — непрозрачно. Ползунок прозрачности внутри Tokyo color picker действует наоборот: `1` — полностью прозрачно.
- Итоговая видимость Chams учитывает Global opacity, Fill opacity и прозрачность выбранного цвета. Fade и Pulse дополнительно изменяют её.
- Приоритет цвета персонажа от высшего к низшему: **текущая цель → rainbow → цвет команды → видимый / скрытый → базовый цвет**. Выключи переопределения, если хочешь видеть базовые Fill / Outline.
- Для независимого цвета рамки выключи **Match character color**. Прозрачность текста и его обводки регулируются отдельно.
- **Character outline** — силуэт Highlight со стандартной толщиной Roblox. Настраиваемая толщина относится к 2D-рамкам, скелету, линиям и FOV.

### Выбор цели

FOV — радиус в пикселях вокруг центра экрана. Deadzone останавливает поворот камеры, когда цель достаточно близко к центру; выбранная цель при этом сохраняется. Большая Aim speed означает более быстрое наведение. Instant убирает плавность.

Для R6 выбор UpperTorso / LowerTorso использует Torso. Другие отсутствующие части тела исключают цель. Смещение XYZ задаётся в мировых координатах; prediction добавляет скорость HumanoidRootPart × Prediction time. Наведение поворачивает камеру; стрельба и регистрация попаданий остаются механиками игры.

Check walls проверяет путь до выбранной части тела. ESP проверяет видимость до головы; для Highlight дополнительно применяется режим Occluded. Для 2D-элементов проверка головы определяет отображение всего оверлея. Прозрачное стекло с CanQuery может считаться препятствием; вода игнорируется.

### Профили

Укажи имя на вкладке Profiles и нажми **Save profile**. Файлы сохраняются в файловой области executor: `Legit/Universal/configs/<имя>.json`. Сохраняются настройки функций, клавиша, RGB и прозрачность цветов, а также акцент UI. **Load profile** загружает выбранное имя; автоматической загрузки при старте нет.

Для имени разрешены латинские буквы, цифры, пробел, `_` и `-`, до 48 символов. Reset defaults возвращает исходные настройки, включая выключенные ESP и Aimbot. Активное удержание / Toggle при загрузке профиля сбрасывается.

## Проверка

Все рабочие Lua-файлы скомпилированы `luau-compile` 0.746. Интеграционные проверки запускают **настоящую Tokyo Lib** с заглушками Roblox и Drawing API:

```shell
python tests/run.py --luau /path/to/luau
```

Проверены запуск, все вкладки, callbacks настроек и цветов, прозрачность, сохранение / загрузка / сброс профилей, пустая привязка клавиши, некорректные профили, фильтры целей, R6, FOV, стены, задержки, prediction, Chams, рамки, скелет, HP, подписи, выгрузка и повторный запуск.

Это проверка логики с заглушками. Визуальный запуск в Roblox и совместимость с конкретным executor в этой среде не проверялись. Пользовательские персонажи, собственные системы команд / здоровья и другие скрипты камеры могут требовать адаптации. Персонажи, не загруженные на клиент из-за StreamingEnabled, недоступны для ESP и наведения.

## Исходники

- `main.lua` — загрузчик, настройки, интерфейс Tokyo и профили.
- `src/Engine.lua` — ESP, выбор целей, управление камерой и очистка.
- `vendor/Tokyo.lua` — предоставленная пользователем Tokyo Lib с локальными исправлениями.
- `assets/` — ресурсы библиотеки, перенесённые в этот репозиторий.
- `tests/` — проверки без запуска Roblox.

Происхождение библиотеки и список исправлений: [THIRD_PARTY.md](THIRD_PARTY.md).
