# Legit

Скрипт для Criminality с интерфейсом Obsidian. Вкладки: **Aimbot, Combat, Character, ESP, World, Misc, Players, UI Settings**.

## Запуск

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/sinmirka/Legit/main/Legit.lua"))()
```

`Legit.lua` содержит интерфейс, иконки и внутренние модули. Запуск требует одной HTTP-загрузки. Нужны `loadstring`, `getgenv` и файловые функции для профилей. Все игровые функции изначально выключены. Повторный запуск выгружает предыдущий экземпляр.

- **RightShift** — открыть / закрыть меню.
- **ПКМ** — удерживать для Camera Aim после его включения.
- **END** — выгрузить скрипт.

Клавиши и масштаб меняются в UI Settings. Профили сохраняются в файловой области executor: `Legit/Universal/configs/<имя>.json`.

## Возможности

| Вкладка | Содержимое |
| --- | --- |
| Aimbot | Camera Aim и Silent Aim: части тела, FOV, фильтры, приоритеты, prediction; автострельба и перебор целей для Silent |
| Combat | Melee Aura: автоатака / ручные удары, дальность, интервал, часть тела, фильтры |
| Character | Noclip, velocity speed, infinite stamina, spinbot, ограничение частоты прыжков |
| ESP | Игроки, chams / контур, имена, HP, дистанция, экипированный инструмент и downed; scrap, crates, airdrops и dealers |
| World | Освещение, эффекты и Dealer Stock Checker |
| Misc | Instant interaction, Dex, Remote Spy, переподключение, C4 Control, ракеты и Jerk Tool |
| Players | Поиск, Friend / Neutral / Enemy, наблюдение |
| UI Settings | Профили, цвета, масштаб, клавиши, диагностика, выгрузка |

Friend исключает игрока из Camera Aim, Silent и Melee. Enemy повышает приоритет среди целей, прошедших фильтры. Эти пометки действуют до выхода игрока / выгрузки и в профиль не записываются.

FOV — радиус вокруг центра экрана. Full360 у Silent убирает экранное ограничение. Team check можно включить отдельно. Для отсутствующих частей R15 используются соответствия R6. Downed / Ragdolled с HP ≤15 исключается при включённом Skip downed.

## Первая очистка ESP

В предыдущей очистке ESP удалены 32 элемента управления:

- 2D-боксы Full / Corners: рамки, фон, обводка, толщина, длина углов, прозрачность и подбор цвета.
- Скелет, линии к игрокам и отдельная HP-полоска вместе с настройками толщины, позиции, ширины и цветов.
- Rainbow, пульсация, затухание по расстоянию и отдельная общая прозрачность ESP.
- Выбор шрифта и формата имени, смещение, отдельная прозрачность и настройка обводки подписей.
- Подпись команды.

Сохранены chams, контур, основные цвета и их прозрачность, HP-раскраска, фильтры игроков, дальность, имена, числовое здоровье, дистанция, экипированный инструмент, Downed / Ragdolled и размер текста. Подпись инструмента включена по умолчанию и переключается через **ESP → Information → Equipped tool**. Имя отображается вместе с username; шрифт и чёрная обводка фиксированы. ESP объектов сохранён. Старые профили загружаются, а удалённые поля игнорируются; они не восстанавливают удалённые эффекты.

## Silent Aim для Criminality

В качестве референса использован предоставленный `Criminality.lua`, модуль `features/combat/silent_aim`.

При наличии `Events2.Visualize` и `Events.ZFKLF__H` используется событийный путь из Silent Aim V2: обрабатывается реальный выстрел текущего оружия и отправляется отдельный отчёт попадания для каждой дробины. Идентификатор выстрела сохраняется, повторные события пропускаются. Hit chance выбирается один раз на выстрел.

Перед отправкой повторно проверяются цель, стены, FOV, дистанция, друзья, здоровье, downed, оружие и состояние ввода. Выключение, сброс настроек, респавн и выгрузка отменяют ожидающие отчёты. Событийный путь не требует hook API и не привязан к определённому executor.

Событийный режим не требует ammo-полей в оружии и не отменяет настоящий выстрел из-за временного Tool.Enabled=false во время задержки между выстрелами. Отсутствующий или пустой список дробин обрабатывается как одна дробина, как в референсе.

В **UI Settings → Diagnostics → Show combat status** поле **Shot** показывает последнее событие: ожидание Visualize, причину пропуска, отправленные отчёты или ошибку отправки. Отправка отчётов не означает подтверждение урона сервером.

Если событий нет, остаётся адаптер Effects / FastCast с `hookfunction` и `checkcaller`. Universal mode использует Raycast hook и требует `hookmetamethod`, `getnamecallmethod`, `checkcaller`, `getcallingscript`.

Отправленный отчёт и локальный трассер не подтверждают серверный урон. Совместимость протокола с текущей версией игры требует проверки в клиенте.

## Melee Aura

Из модуля `features/combat/melee_aura` референса перенесены вызовы `XMHH.2` / `XMHH2.2`, формат идентификатора, задержка перед попаданием и интервалы оружия. Два сообщения одного удара используют один идентификатор.

При наличии обеих игровых RemoteEvent используется этот путь; иначе остаётся Raycast adapter. Для swing handshake выбирается единственная RemoteFunction в ReplicatedStorage: при нескольких кандидатах случайная функция не вызывается. Это отличие от референса, который берёт первую найденную функцию; такой случай требует проверки структуры игры.

Интервал атаки учитывает настройку пользователя и минимальную задержку оружия из референса. Одновременно выполняется один ожидающий удар. После задержки повторно проверяются фильтры, дальность, здоровье, персонаж и экипировка. Ручной режим отправляет удар после `Tool.Activated`.

## Wall Bang

**Combat → Wall Bang** повторяет логику референса: разрешает выбор целей за стенами для Camera Aim, Silent Aim и Melee Aura. По умолчанию выключен и сохраняется в профиле. Собственные настройки Check walls сохраняются; после выключения Wall Bang они снова действуют. Остальные фильтры продолжают работать. Переключение отменяет ожидающие отчёты попаданий. Эта опция отключает проверку видимости, а серверный урон через стены нужно проверить в игре.

## Диагностика

В UI Settings → Diagnostics доступны Show combat status, Start debug capture, Stop debug capture, Copy debug report, Save debug report и Clear debug log. Общий capture собирает диагностику без включения атак.

Отчёт сохраняется в `Legit/Universal/logs/latest.txt`. Буфер ограничен 400 записями; частые сообщения ограничены по частоте. Логирование по умолчанию выключено. Отчёты не отправляются в сеть автоматически.

`tools/probe_runtime.lua` проверяет доступные API без полной загрузки интерфейса. `tools/probe_gun_pipeline.lua` предназначен для исследования структуры оружия.

## Сборка и проверки

Для инструментов разработки нужен Node.js 20+ без дополнительных пакетов, для проверок — Luau CLI.

```shell
node tools/build.mjs
node tests/run.mjs --luau /path/to/luau --compiler /path/to/luau-compile
```

Сборка обновляет `Legit.lua` и `loader.lua`. Необязательный `node tools/build.mjs --iris` также пересобирает сохранённый архивный Iris bundle. В рабочем интерфейсе используется Obsidian.

Проверки компилируют 17 рабочих Lua-файлов, включая настоящий интерфейс, и запускают 20 сценариев с заглушками Roblox. Покрыты UI, профили, приоритеты, фильтры, ESP, управление персонажем, очистка, исходные combat adapters и новые событийные пути. Для новых механизмов проверяются дробь, дубликаты, интервалы оружия, ручные удары и отмена отложенных действий. Проверки с заглушками не заменяют запуск в игре.

Исходники находятся в `src/`, точка входа — `main.lua`. Обновляй исходники и пересобирай автономный файл перед коммитом. Сторонние библиотеки и лицензии перечислены в `THIRD_PARTY.md`.

## Что можно перенести позже

Следующие модули есть в предоставленном референсе, но в этой работе не добавлены:

- **Auto refill / deposit / allowance / tool pickup** — пополнение запасов, депозит, получение allowance и подбор инструментов.
- **Key ESP и расширенный ESP** — отображение ключей и дополнительные виды объектов.

- **Lockpick helpers** — помощь с интерфейсом взлома и взаимодействием с сейфами.

Каждый перенос нужно отдельно адаптировать к текущей структуре игры и проверить.

## Поэтапный поиск объектов и редкость Scrap

Включение ESP только планирует поиск. Общий WorldScanner обходит дерево через GetChildren: до 48 операций за кадр с временным бюджетом около 2 ms между операциями. Workspace:GetDescendants и рекурсивные обходы моделей в ESP объектов и Stock Checker не используются. Очередь streaming ограничена. За обновление ESP создаётся не более восьми подсветок/подписей, поэтому объекты появляются постепенно.

Устранён найденный синхронный источник фриза. Фактическую плавность на текущей карте ещё нужно проверить в клиенте.

**ESP → Values / Criminality objects → Minimum scrap rarity**: All, Common, Uncommon, Rare, Epic, Legendary, Mythic. Выбор Rare показывает Rare и выше. Данные читаются из Rarity / Tier / Quality. Неизвестная редкость подписана Unknown и показывается только с All.

## Dealer Stock Checker

**World → Dealer stock**: включи Dealer Stock Checker. В Items оставь All или введи названия/части названий через запятую, например AKS, M4. Show dealer stock выводит кеш; Notify stock changes уведомляет об изменениях после начального снимка. Читаются только значения, реплицированные клиенту под объектами дилеров/stock. Отсутствие данных не считается нулевым наличием.

## C4 Control и ракеты

**Misc → C4 and rocket control**: включи C4 Control и/или Rocket control, затем запусти оружие обычным способом. Камера переводится на снаряд, направление задаётся камерой и движением, скорость — Projectile speed. **X** или Release projectile отпускает управление.

Поддерживаются TransIgnore для C4 и имена снарядов RPG, Grenade Launcher, AT4, SBL, Panzer, Firework Launcher и Hallows из референса. Подхватывается один собственный снаряд: по Creator/Owner либо рядом после недавней активации подходящего оружия. Явно чужой владелец исключается.

Исходные camera subject, Anchored/Massless и временно отключённые mover-объекты восстанавливаются при отпускании, отключении, взрыве C4, удалении снаряда, смерти, респавне и выгрузке. Наведение и melee во время управления приостановлены. Выбор spectate отпускает снаряд. Реальная управляемость зависит от сетевого владения и ограничений игры; локальные тесты этого не подтверждают.

## Jerk Tool

**Misc → C4 and rocket control → Jerk Tool** создаёт локальный инструмент Jerk в рюкзаке. Экипируй и активируй; повторная активация останавливает анимацию. Используются R6/R15 animation IDs из референса. Снятие инструмента, смерть, выключение и выгрузка останавливают анимацию; после респавна инструмент пересоздаётся. Доступность анимаций определяется Roblox.
