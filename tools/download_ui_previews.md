# Скачать PNG-примеры UI Libraries

Нужен Python 3.9 или новее; дополнительные пакеты не нужны.
Из корня проекта:

```powershell
python tools/download_ui_previews.py
Start-Process ui-previews/index.html
```

Скрипт скачивает архив `GhostDuckyy/UI-Libraries` (ветка `main`), сохраняет
все PNG с исходной структурой папок и дополнительно загружает PNG по HTTP(S)
ссылкам из Markdown-файлов. Внешние картинки лежат в `linked-previews`
соответствующей библиотеки; имя вычисляется из URL, чтобы избежать совпадений.
Выгрузка по умолчанию находится в `ui-previews/` и исключена из Git.

`index.html` — локальная галерея с названиями папок и открытием оригинала по клику.
`failed-downloads.json` — ссылки, которые скачать не удалось, и причины ошибок.
Недоступные внешние ссылки не прерывают остальные загрузки; ошибки скачивания
архива завершают скрипт с кодом 1. Картинки, существующие только по недоступным
ссылкам, восстановить из этого репозитория нельзя.

Для другой папки используй `--output "D:\Pictures\UI"`.
`--local-only` скачивает только PNG, находящиеся непосредственно в репозитории.
Повторный запуск обновляет файлы и отчёт, не удаляя другие файлы в папке.
